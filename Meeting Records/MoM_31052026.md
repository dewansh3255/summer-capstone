### 2.3 Data Collection Plan
- **Target:** Data from **5 participants** to be collected over **2 days**
  - Day 1: 3 participants
  - Day 2: 2 participants
- **Protocol:** Each participant performs **10 gestures × 3 orientations**
- **Estimated duration per participant:** 40–50 minutes
- **Data modalities recorded per session:**
  - EMG signals (via Delsys Trigno sensors)
  - Hand image/depth data (via Meta Quest headset)
- The combined EMG + Meta Quest dataset will serve as the foundation for the recognition pipeline.

### 2.4 Synchronisation — Query Raised
- **Query (Dewansh):** Is there explicit synchronisation between the EMG and image data streams, or are they only time-stamped independently?
- **Response (Kirti):** The Python script handles synchronisation. Both data streams are initiated simultaneously when the script is launched, functioning similarly to a Lab Streaming Layer (LSL) setup. Any residual lag or drift between the two streams will be addressed during the preprocessing stage.

### 2.5 Pre-Data-Collection Tasks
Before the hardware handover, Dewansh is expected to complete hands-on exploration of both data modalities independently.

#### Modality 1 — Computer Vision
- Study **MediaPipe** and **OpenCV**; refer to the paper shared by the supervisor, which demonstrates background removal from gesture images
- Capture **2–3 self-photographs** of hand gestures (e.g., thumbs up, victory sign) against a plain white background
- Build a pipeline to:
  1. Detect the hand using MediaPipe
  2. Remove the background using OpenCV
  3. Compute **Chamfer Distance** between gesture shapes

#### Modality 2 — EMG
- Review the **EMG Bench paper** shared earlier, which covers standard EMG preprocessing workflows
- Note: While some literature converts EMG signals to heatmap images, this project will retain EMG as **raw time-series signals**
- Select **one open-source EMG dataset** from available options (e.g., **NinaPro DB1, DB2**):
  - Process data from **one subject only**
  - Understand the raw data format
  - Apply standard preprocessing steps
  - Inform the supervisor of the chosen dataset
